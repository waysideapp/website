Wayside Test Provider

A pretend camera database subscription, used to test how Wayside imports a provider's download and notices its new releases. The positions are invented and are not real cameras.

Download

  • wayside-test-cameras.zip — the CSV and Release.txt together, version 1.002. Import this ZIP in Wayside.
  • wayside_test_cameras.csv and Release.txt — the same two files unzipped, for testing Select All in Files.
  • releases.xml — the release feed. Its newest item is 1.003, so an import of the ZIP is told an update is available.

To simulate a new release, add an item with a higher version number to the top of the feed.
