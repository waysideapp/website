Wayside Community Database

The camera database Wayside downloads when no other database has been imported. It covers fixed speed cameras and red-light cameras in Great Britain, and is rebuilt every Sunday from the data published by Lufop.net under CC BY-SA 4.0.

Files

  • gb-cameras.zip — the database the app downloads. One CSV, gb-cameras.csv, with a row per camera: longitude, latitude, the rule (max @30 or stop) and Lufop's description.
  • manifest.json — when the data was published by Lufop, when it was last checked, and how many cameras of each kind it holds.

Mobile camera sites and average speed cameras are not included. Corrections to the positions themselves go to Lufop.net, whose data this is. The build script is build.py.
